# Programming in Practice: C Portfolio

This repository contains my weekly C programming laboratory tasks and modules completed throughout the semester. Each directory includes the human-readable source code (`.c`) alongside the compiled machine-executable binary file (`.exe`).

## Repository Structure

* **`Budget/`** : Municipal Budget Calculator evaluating total revenues, expenses, surpluses, and deficits.
* **`Salary/`** : Employee Income System managing basic pay scales, housing/transport allowances, taxes, and income classifications.
* **`Numbers_Input/`** : Sequential array manipulation scripts demonstrating `for`, `while`, and `do-while` control structures (`For6numbers.c`, `While6numbers.c`, `Enter6numbers.c`).
* **`Financial_Management_System/`** - Final Project: An integrated platform combining baseline municipal descriptive metrics with functional budget routines.

## Compilation and Execution
To execute any module locally, navigate to the specific directory and run the compiled application:
```bash
# Example for running the integrated management system
./main.exe
```
